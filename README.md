# PowerPoint オブジェクトドラッグ・アドイン

PowerPointのスライドショー中に、特定の図形をマウスやタッチで自由に移動させることができるアドインです。
塾の授業やプレゼンテーションで、カードを並び替えたり、オブジェクトを動かして説明したりする際に最適です。

---

## 🚀 インストール方法

講師の皆様がご自身のPCに導入する手順です。

1.  **ファイルのダウンロード**: [GitHubのReleasesページ](https://github.com/Tokuya-Satou/PPT_AddIn/releases)から最新の `PPT_DragDrop_Addin.zip` をダウンロードし、右クリックして「すべて展開」します。
2.  **インストールの実行**: 展開したフォルダ内にある `setup.exe` をダブルクリックします。
3.  **確認**: インストール画面が表示されたら「インストール」をクリックしてください。
4.  **PowerPointの起動**: PowerPointを開くと、リボンに **「PPTドラッグ」** というタブが追加されています。

> [!IMPORTANT]
> `setup.exe` だけでなく、同じフォルダにある `Application Files` などのファイル一式が必要です。必ずZIPを解凍してから実行してください。

## 📖 使い方

### 1. 動かしたい図形を設定する
動かしたい図形（画像やテキストボックスなど）の名前の先頭に **`Drag_`** を付けます。
- 例: `Drag_Card1`, `Drag_Apple`
- 名前を変更するには、[ホーム]タブ > [配置] > [オブジェクトの選択と表示] パネルを使うと便利です。

### 2. アドインを有効にする
リボンの **「PPTドラッグ」** タブを開き、機能を有効にします。

### 3. スライドショーを開始
スライドショーを開始すると、`Drag_` と名付けた図形をマウスでドラッグして移動できるようになります。
- **自動復元**: スライドショーを終了すると、動かした図形は自動的に元の位置に戻ります。

---

## ✨ 主な機能

- **マウス・タッチ対応**: 直感的な操作でオブジェクトを移動。
- **ペンプロファイル**: 3つの独立したペン（色設定可能）と蛍光ペンを切り替え可能。
- **動的ペンパレット**: スライドショー中に表示されるパレットで、色の変更やスライド送りが可能。
- **リセット機能**: 終了時に位置をリセットするため、教材ファイルを汚しません。
